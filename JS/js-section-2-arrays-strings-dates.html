1. Arrays and traversal

  • An array is an ordered, zero-indexed, resizable list, and a special object (typeof [] === "object"; use Array.isArray(x)). Elements can be of mixed types.
  • Create: [1,2], new Array(3) (3 empty slots), Array.of(3) ([3]), Array.from("abc"), Array.from({length:3},(_, i)=>i).
  • length is writable: arr.length = 0 clears; setting smaller truncates. arr[arr.length] is undefined (last item is length-1). arr.at(-1) gives the last.
const arr = ["ES5","ES6","ES7","ES8"];
for (let i = 0; i < arr.length; i++) {}          // classic: break/continue/await OK
for (const v of arr) {}                           // values, any iterable, break OK
for (const [i, v] of arr.entries()) {}            // index + value
arr.forEach((v, i, a) => {});                     // no break, return value ignored
for (const i in arr) {}                           // KEYS as strings, includes inherited: avoid

Traversal methods compared

Trap: the course snippet using break inside forEach is a SyntaxError: Illegal break statement, so nothing runs at all. return inside forEach only skips that one callback. To stop early use for...of, some(), every() or find().
arr.forEach(async x => await f(x)) does not wait. Use for...of with await, or Promise.all(arr.map(...)).
new Array(3).map((_, i) => i) returns three empty slots: map skips holes. Array(3).fill({}) shares ONE object across slots.
for...in vs for...of?

for...in iterates enumerable property keys (strings, includes inherited and added props, order not guaranteed for non-integer keys); use it on objects. for...of iterates values of any iterable (arrays, strings, Map, Set, generators) and cannot iterate plain objects.

Output of arr[arr.length] with [7,9,0]?

undefined. Index 3 does not exist; reading a missing index never throws.

How do you copy an array? Shallow vs deep?

[...a], a.slice(), Array.from(a) are shallow (nested objects shared). Deep: structuredClone(a). JSON.parse(JSON.stringify(a)) loses undefined, functions, Dates and NaN.

What is a sparse array / hole?

Slots with no value, made by delete a[1], [1,,3] or new Array(3). forEach/map skip them, for...of reads them as undefined. Avoid; use fill or Array.from.

const a = [1, 2, 3];
a.push(4);          // 4   -> [1,2,3,4]
a.unshift(0);       // 5   -> [0,1,2,3,4]   (O(n): shifts every index)
a.pop();            // 4   -> [0,1,2,3]
a.shift();          // 0   -> [1,2,3]
a.splice(1, 0, "x");        // []         insert at 1  -> [1,"x",2,3]
a.splice(1, 1);             // ["x"]      remove one

a.splice(-1);               // [3]        remove last
a.splice(1, 0);             // []         nothing removed -> returns empty array
a[1] = "z";                 // replace by index
a.with(1, "q");             // non-mutating replace (new array)

const i = a.indexOf("z"); if (i > -1) a.splice(i, 1);   // remove a specific value
const b = a.filter(v => v !== "z");                      // non-mutating removal
Trap: splice (mutates, takes a count) vs slice (copy, takes an end index) is a classic mix-up. Removing inside a forward loop skips items, so loop backwards or use filter. React state must not be mutated: use spread/filter/map instead of push/splice.
push vs unshift? pop vs shift?

push/pop work at the end (fast, O(1)); unshift/shift work at the start and re-index everything (O(n)). push/unshift return the new length; pop/shift return the removed element.

What does splice return when nothing is removed?

An empty array [], even if items were inserted.

How do you insert at a given position and remove a specific element?

Insert: arr.splice(pos, 0, item). Remove: find with indexOf then splice(i,1), or filter. Remove all duplicates of a value: filter.

How do you remove duplicates?

[...new Set(arr)] for primitives. For objects, dedupe by key with a Map or filter((x,i,a)=>a.findIndex(y=>y.id===x.id)===i).

find vs filter?

find returns the first matching element (or undefined) and stops; filter returns an array of all matches (possibly empty) and always scans everything.

indexOf vs includes?

indexOf returns a position (-1 if absent), includes returns a boolean and handles NaN. Use includes for existence checks.

What does findIndex return when nothing matches?

-1 (while find returns undefined).

4. map()

map(cb(value, index, array)) returns a new array of the same length with each callback result. It doesn't mutate the original. The callback must return (curly-brace arrows need an explicit return).

["apple","fig"].map(s => s.length);          // [5, 3]
[4, 9, 16].map(Math.sqrt);                   // [2, 3, 4]
const products = [{pCode:1,pName:"Apple"},{pCode:2,pName:"Banana"}];
products.map(p => p.pName);                  // ["Apple","Banana"]
products.map(p => ({ ...p, price: 10 }));    // add field (parentheses for object)
products.map(p => { p.pName })               // [undefined, undefined]: no return!
["1","2","3"].map(parseInt);                 // [1, NaN, NaN]
["1","2","3"].map(Number);                   // [1, 2, 3]
  • Chaining: users.filter(u=>u.active).map(u=>u.name).sort().
  • map vs forEach: map for building a new array; forEach for side effects only.
  • Polyfill idea (common interview ask): Array.prototype.myMap = function(cb){ const r=[]; for(let i=0;i<this.length;i++) if(i in this) r[i]=cb(this[i],i,this); return r }
Can map be used instead of forEach? Does it mutate?

It works but allocates an unused array; use forEach for side effects. map doesn't mutate the source, but callbacks that mutate objects inside it will (objects are shared).

5. Flatten and reduce()

Flatten

const nested = [1, [2, [3, [4]]]];
nested.flat();            // [1,2,[3,[4]]]  depth 1 by default
nested.flat(Infinity);    // [1,2,3,4]
[].concat(...[[1,2],[3]]);                       // 2D only: [1,2,3]
[[1,2],[3]].reduce((acc, x) => acc.concat(x), []);// [1,2,3]
["a b","c"].flatMap(s => s.split(" "));          // ["a","b","c"] (map + flat depth 1)
const flatten = a => a.reduce((r, x) => Array.isArray(x) ? [...r, ...flatten(x)] : [...r, x], []); // recursive

reduce(callback(acc, cur, i, arr), initial)

const employees = [{eNo:1001,salary:3000},{eNo:1002,salary:2200},{eNo:1003,salary:3400},{eNo:1004,salary:6000}];
const total = employees.reduce((sum, e) => sum + e.salary, 0);   // 14600
const avg = total / employees.length;                            // 3650
[1,2,3,4].reduce((a, b) => a * b, 1);                            // 24 product
[].reduce((a, b) => a + b);        // TypeError: no initial value on empty array
[].reduce((a, b) => a + b, 0);     // 0
["a","b"].reduceRight((acc, c) => acc + c);   // "ba" (right to left)

// groupBy / count with reduce
["a","b","a"].reduce((m, k) => (m[k] = (m[k] || 0) + 1, m), {});   // {a:2, b:1}
Math.max(...employees.map(e => e.salary));                      // 6000
Trap: always give reduce an initial value; without it the first element becomes the accumulator and an empty array throws. Forgetting to return acc makes the next iteration receive undefined. flat() also removes holes. Newer engines have Object.groupBy and Map.groupBy; check support.
reduce vs reduceRight?

Same logic, but reduceRight walks from the last index to the first. It matters for non-commutative operations like string building or function composition.

Write reduce as a polyfill or use it to implement map/filter?

map = (a,f)=>a.reduce((r,x,i)=>(r.push(f(x,i)),r),[]). Using reduce to build everything is possible but less readable than the dedicated methods.

6. Sorting

  • sort() mutates the array and returns the same array. Default order converts items to strings and compares UTF-16 code units.
  • Comparator (a,b)=>n: negative keeps a before b, positive puts b first, 0 keeps order. Sort is stable (ES2019).
  • Non-mutating copy: toSorted() (ES2023) or [...arr].sort().
[10, 9, 1, 100].sort();                  // [1, 10, 100, 9]  string order!
[10, 9, 1, 100].sort((a, b) => a - b);   // [1, 9, 10, 100]  ascending
[10, 9, 1, 100].sort((a, b) => b - a);   // [100, 10, 9, 1]  descending
[3, undefined, 1, , 2].sort();           // [1, 2, 3, undefined, <empty>]: undefined last, holes after
["b","a","C"].sort();                    // ["C","a","b"] uppercase first
["b","a","C"].sort((x, y) => x.localeCompare(y));       // ["a","b","C"]
["é","e","z"].sort(new Intl.Collator("fr").compare);

const emps = [{n:"Raj",s:3000},{n:"Anu",s:2200}];
emps.sort((a, b) => a.s - b.s);          // by number key
emps.sort((a, b) => a.n.localeCompare(b.n));  // by string key
// "sorting an object literal": sort its entries, rebuild
const o = {b:2, a:1};
Object.fromEntries(Object.entries(o).sort(([k1],[k2]) => k1.localeCompare(k2))); // {a:1,b:2}
Trap: a comparator returning a boolean ((a,b)=>a>b) is wrong: true/false become 1/0 and never -1. undefined values are never passed to the comparator; they always sort to the end. Sorting state arrays in React mutates state; copy first. reverse() also mutates.
Why does [10,9,1].sort() give [1,10,9]?

Elements are compared as strings: "1" < "10" < "9" character by character. Provide a numeric comparator.

How do you shuffle an array fairly?

Fisher-Yates: loop from the end, swap with a random earlier index. sort(()=>Math.random()-0.5) is biased.

7. Array destructuring

Destructuring unpacks values from an iterable into variables by position. Works on any iterable (strings, Sets, Maps, generators).

let [a, b, c] = [5, , 7];        // a=5 b=undefined c=7 (hole skipped, not shifted)
const [x, , z] = [1, 2, 3];      // skip with an empty slot: x=1 z=3
const [p = 10, q = 20] = [1];    // defaults: p=1, q=20 (only for undefined)
const [m = 9] = [null];          // m = null (null is NOT undefined)
const [h, ...t] = [1, 2, 3];     // t=[2,3] rest must be last
const [[n1, n2], n3] = [[1, 2], 3];   // nested
[a, b] = [b, a];                 // swap, no temp variable
const [first] = "hello";         // "h"
function minMax(a){ return [Math.min(...a), Math.max(...a)] }
const [lo, hi] = minMax([4, 2, 8]);   // return multiple values
const [k, v] = Object.entries({id: 7})[0];   // "id", 7
Trap: the swap line after a statement without a semicolon (let a=1, b=2 \n [a,b]=[b,a]) gets glued to the previous line by ASI. Start with ;. Destructuring null or undefined throws TypeError. Default expressions are evaluated lazily.
What is destructuring assignment?

Syntax that unpacks array elements (by position) or object properties (by name) into distinct variables in one statement, with support for defaults, skipping, rest and nesting.

8. Strings basics and Unicode (UTF-16)

  • Strings are immutable primitives: s[0] = "x" silently does nothing (throws in strict mode); methods return new strings.
  • Declare: 'single', "double", `template`, String(123); new String("a") creates an object (typeof is "object", avoid).
  • JS stores strings as UTF-16 code units. Characters beyond U+FFFF (emoji, some CJK) use two units (a surrogate pair), so length counts units, not visible characters.
"\u0041";          // "A"  (4-hex escape)
"\x41";            // "A"  (2-hex escape)
"\u{1F600}";       // 😀  (code point escape, any length, ES6)
"\u{1F600}".length;            // 2
[..."\u{1F600}"].length;       // 1  (iterates by code point)
"😀".codePointAt(0);           // 128512  (charCodeAt gives only the first half: 55357)
String.fromCodePoint(128512);  // "😀"
"A".charCodeAt(0);             // 65
"café" === "cafe\u0301";       // false; fix with .normalize()
"cafe\u0301".normalize() === "café";  // true
"line1\nline2", 'It\'s', "say \"hi\"", "C:\\path"   // common escapes
"abc"[1], "abc".at(-1);        // "b" "c"
"a" < "b", "a" < "B";          // true false (compares code units)
Trap: reversing with str.split("").reverse().join("") breaks emoji (splits surrogate pairs); use [...str]. "5" + 3 is "53" but "5" - 3 is 2. isWellFormed() (new) detects broken surrogates.
Ways to declare a string? How do you handle Unicode and long code points?

Quotes, backticks, String(). For Unicode use \uXXXX for BMP characters and \u{XXXXX} for longer ones, codePointAt/fromCodePoint to convert, spread or for...of to iterate by code point, normalize() to compare accents, and Intl.Segmenter for true user-perceived characters.

Primitive string vs String object?

"a" === "a" true; new String("a") === new String("a") false (object identity). JS auto-wraps primitives to call methods and discards the wrapper.

9. Template literals

  • Backtick strings with ${expression} interpolation (any expression, even function calls, ternaries, nested templates), real multi-line text, and tagged templates.
  • Advantages: readability over + concatenation, multi-line without \n, auto string conversion, safer HTML/SQL building via tags.
const n = "Asha", a = 30;
`Hi ${n}, next year you'll be ${a + 1}`;     // expression inside
`${a > 18 ? "adult" : "minor"}`;             // ternary
`line 1
line 2`;                                      // keeps the newline
`<li>${items.map(i => `<b>${i}</b>`).join("")}</li>`;   // nested
`\${not interpolated}`;                       // escape with backslash
`${[1,2]}`, `${{}}`, `${null}`;               // "1,2" "[object Object]" "null"

function tag(strings, ...vals){ return strings.raw.join("|") + vals.join(",") }
tag`a${1}b${2}c`;   // "a|b|c1,2"  (strings array + values)
String.raw`C:\new`;  // "C:\new" (no escape processing)
What is a template literal and how do you display an expression?

A backtick-delimited string literal (ES6) that evaluates ${...} expressions and converts them to strings, supports multi-line text and tag functions (used by styled-components, GraphQL gql, lit-html).

search() vs indexOf()?

search takes a regex (or converts a string to one, so special chars like . act as patterns) and has no start offset; indexOf takes a literal string and an optional start index. Neither is global. indexOf is faster for plain text.

Explain the output of indexOf("is",5) and lastIndexOf("is",1).

First: search for "is" starting at index 5, found at 5. Second: search backwards starting at index 1; the only candidates start at 0 or 1 ("Th", "hi"), so no match, -1.

slice vs substring vs substr?

Reverse a string / check palindrome / count characters?

[...s].reverse().join(""); palindrome: compare with its reverse after lowercasing and stripping non-alphanumerics (s.replace(/[^a-z0-9]/gi,"")); count: loop with an object or reduce.

12. Case conversion and replace()

"Hello".toUpperCase(); "Hello".toLowerCase();   // "HELLO" "hello"
"a-b-a".replace("a", "X");        // "X-b-a"  only FIRST match (string pattern)
"a-b-a".replace(/a/g, "X");       // "X-b-X"  global regex replaces all
"a-b-a".replaceAll("a", "X");     // "X-b-X"  (ES2021); string patterns allowed
"John Smith".replace(/(\w+) (\w+)/, "$2, $1");   // "Smith, John" ($1 = capture group)
"a1b2".replace(/\d/g, d => d * 2);               // "a2b4" (callback)
"hello world".replace(/\b\w/g, c => c.toUpperCase()); // "Hello World"
"İ".toLowerCase().length;                         // locale/unicode quirks exist
s.toLocaleUpperCase("tr");

// vowel or consonant
function check(ch){
  if (!/^[a-z]$/i.test(ch)) return "not a letter";
  return "aeiou".includes(ch.toLowerCase()) ? "vowel" : "consonant";
}
check("E");  // "vowel"
Trap: strings are immutable, so s.toUpperCase() alone changes nothing; you must use the return value. replaceAll with a regex lacking /g throws TypeError. In the replacement string, $& is the match and $$ a literal dollar.
How do you replace all occurrences?

replaceAll("x","y") or replace(/x/g,"y"); older code used split("x").join("y").

Capitalise the first letter of each word?

s.split(" ").map(w => w[0].toUpperCase() + w.slice(1)).join(" ") (guard empty words) or the regex callback above.

13. Date and time basics

  • A Date is an object holding milliseconds since 1 Jan 1970 UTC (the epoch). It displays in the local time zone but stores UTC.
  • Months are 0-indexed (0 = January); days of the month are 1-31; getDay() is 0 (Sunday) to 6.
new Date();                         // now
new Date(0);                        // epoch (ms number)
new Date("2020-09-23");             // ISO string
new Date(2020, 8, 23, 10, 30, 15, 500); // y, month(0-11), d, h, m, s, ms  (local)
new Date(otherDate);                // copy
Date.now();                         // number, ms now (not a Date)
Date.UTC(2020, 8, 23);              // ms, UTC-based
+new Date(); new Date().getTime();  // number

const dt = new Date(2020, 08, 23);  // 23 September 2020, 00:00:00 local time
console.log(dt);                    // Wed Sep 23 2020 00:00:00 GMT+0530 (India Standard Time)
new Date(2020, 0);                  // 1 Jan 2020 (day defaults to 1)
new Date(99, 0);                    // year 1999! (0-99 maps to 1900-1999)
new Date("invalid");                // Invalid Date; getTime() is NaN

ISO 8601 formats JS understands

  • YYYY, YYYY-MM, YYYY-MM-DD (date-only is parsed as UTC).
  • YYYY-MM-DDTHH:mm, ...:ss, ...:ss.sss with no zone is parsed as local time.
  • Add Z (UTC) or an offset +05:30. toISOString() always gives YYYY-MM-DDTHH:mm:ss.sssZ.
  • Non-ISO strings like "23/09/2020" or "Sep 23, 2020" are implementation-dependent; avoid.
Trap: new Date("2020-09-23") is UTC midnight, so in US time zones it displays as 22 Sep evening, while new Date("2020-09-23T00:00") is local. In the course snippet 08 works only in sloppy mode; in strict mode/modules a leading-zero literal like 08 is a SyntaxError, so write 8. A Date is an object: d1 == d2 is false for equal times; compare d1.getTime() === d2.getTime(). d1 < d2 works because of valueOf.
Different ways of creating a Date?

No args (now), milliseconds number, date string (ISO preferred), components (y, m, d, h, mi, s, ms), or another Date; Date.now() for a timestamp number only.

Why is Date considered painful and what is the fix?

Mutable, 0-based months, parsing inconsistencies, poor time zone support. Use Intl.DateTimeFormat, libraries like date-fns/Day.js, or the upcoming Temporal API (check browser support before using).

Setters mutate the date and return the new timestamp. Values that overflow roll into the next unit.

const d = new Date(2020, 8, 23);
d.getMonth();                                   // 8 (not 9!)
["Jan","Feb","Mar","Apr","May","Jun","Jul","Aug","Sep","Oct","Nov","Dec"][d.getMonth()]; // "Sep"

// date 50 days before
const before = new Date(d);          // copy first! setters mutate
before.setDate(before.getDate() - 50);   // Aug 4 2020 (rolls back across months)

// overflow in constructor
new Date(2020, 0, 35);   // Feb 4 2020  (Jan has 31 days; 35 - 31 = 4)
new Date(2020, 12, 1);   // Jan 1 2021  (month 12 rolls the year)
new Date(2020, 1, 30);   // Mar 1 2020  (2020 leap year: Feb has 29)
new Date(2021, 2, 0);    // Feb 28 2021 (day 0 = last day of previous month)
new Date(y, m + 1, 0).getDate();   // number of days in month m

// add days helper
const addDays = (dt, n) => { const r = new Date(dt); r.setDate(r.getDate() + n); return r };
Trap: getDate() is the day of the month, getDay() the weekday. const x = d; x.setDate(1) also mutates d (same reference). toString() output is local, toISOString() is UTC, toJSON() uses ISO.
Output of adding 35 as the date in new Date(2020, 0, 35)?

4 February 2020, local midnight. Overflowing days roll into following months; the constructor does not validate.

How do you check whether a Date is valid? Format as dd/mm/yyyy?

d instanceof Date && !isNaN(d). Format: d.toLocaleDateString("en-GB") gives 23/09/2020, or pad parts manually with String(n).padStart(2,"0").

15. Time methods and date arithmetic

const d1 = new Date("2024-01-01"), d2 = new Date("2024-03-01");
const MS_DAY = 24 * 60 * 60 * 1000;
(d2 - d1) / MS_DAY;                        // 60 (subtraction gives ms)
Math.round((d2 - d1) / MS_DAY);            // round to absorb DST hour shifts for local dates
Math.floor(Math.abs(d2 - d1) / MS_DAY);    // whole days, either order

const t = new Date();

Calculate the date difference in days.

Subtract the two dates (milliseconds), divide by 86,400,000, then round or floor depending on whether partial days count.

How do you change hours or minutes?

setHours(h, m, s, ms) and setMinutes; overflow carries (e.g. setMinutes(75) adds 1 hour 15 min). Work on a copy to avoid mutating the original.

Compare two dates / find the day of the week?

Compare with getTime() or relational operators (never ==). Weekday: ["Sun",...][d.getDay()] or toLocaleDateString("en-US",{weekday:"long"}).
